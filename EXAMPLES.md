## How to Use These Examples

### Download and Open

1. **Click on any file link above** or navigate to the `examples/` directory
2. **Download the .pptx file** to your computer
3. **Open with**:
   - Microsoft PowerPoint (Windows/Mac)
   - LibreOffice Impress (Windows/Mac/Linux)
   - Google Slides (upload to Google Drive)
   - Apple Keynote (Mac/iOS)
   - Any PowerPoint-compatible application

### Verify the Output

When you open these files, you should see:
- ✅ Proper slide layouts with title and content areas
- ✅ Readable text with correct formatting
- ✅ Bullet points properly displayed
- ✅ Consistent styling across slides
- ✅ No errors or warnings when opening

### Inspect the XML Structure

To examine how these presentations are built:

```bash
# Extract the ZIP archive
unzip -d extracted_pptx examples/simple_example.pptx

# View the XML structure
tree extracted_pptx/

# Examine specific XML files
cat extracted_pptx/ppt/presentation.xml
cat extracted_pptx/ppt/slides/slide1.xml
```

You'll see the PowerPoint Open XML structure:
- `[Content_Types].xml` - File type definitions
- `ppt/presentation.xml` - Main presentation structure
- `ppt/slides/slide*.xml` - Individual slide content
- `ppt/slideLayouts/` - Layout templates
- `ppt/slideMasters/` - Master templates
- `ppt/theme/theme1.xml` - Theme definitions

## Generating Your Own Examples

To generate custom presentations:

```python
from pptx_generator import PPTXGenerator

# Create generator
ppt = PPTXGenerator()

# Add slides
ppt.add_title_slide("My Presentation", "Subtitle Here")
ppt.add_content_slide("Topics", ["Point 1", "Point 2", "Point 3"])

# Save
ppt.save("examples/my_example.pptx")
```

Or run the example scripts:

```bash
# Generate simple example
python example.py

# Generate all Comic-Analysis presentations
python comic_analysis_presenter.py
```
